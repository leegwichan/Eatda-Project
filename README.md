# 잇다 - 맛집 탐색에 도움을 주는 참여형 맛집 플랫폼

## 실행 방법

[Docker Desktop](https://www.docker.com/products/docker-desktop/)을 설치한 후, 프로젝트 루트에서 아래 명령어를 실행합니다:

```bash
docker compose up -d
```

실행 후 http://localhost:3000 으로 접속할 수 있습니다.

> 자세한 내용은 [Docker 실행 가이드](docs/docker-guide.md)를 참고하세요.
> 새로운 가게 검색 & 응원 등록 기능 필요한 경우 [카카오 API 키 설정](docs/kakao-api-setup.md)을 참고하세요.
